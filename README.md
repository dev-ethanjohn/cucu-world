# Cucu World

An interactive Three.js community atlas and aggregate registration dashboard.

This repository publishes a **dated snapshot**, not a live database connection. Reload snapshot reloads the published JSON; updating totals requires a new publication.

Country/region is the saved device Region setting. It does not establish residence, nationality or where an account was registered. No usernames, email addresses or database credentials are included.
